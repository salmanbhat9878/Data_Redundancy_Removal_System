Data Redundancy Removal System

Project Overview

The Data Redundancy Removal System is a Python-based application that uses SQLite to store records and prevent duplicate email entries.

Objectives

- Store user records in an SQLite database.
- Detect duplicate email addresses.
- Validate user input.
- Prevent duplicate records.

Technologies Used

- Python
- SQLite3
- VS Code

Features

- Add user records
- Duplicate email detection
- Email validation
- Blank name validation
- Blank email validation
- Display saved records

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python main.py

Project Files

- "main.py" – Main Python application.
- "redundancy.db" – SQLite database.

Conclusion
